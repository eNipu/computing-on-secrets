# Computing on Secrets: figures and code

Companion sources for
[Computing on Secrets: An Illustrated Guide to LWE and Homomorphic Encryption](https://al-am.in/writing/computing-on-secrets-lwe-homomorphic-encryption).

Every animation and diagram in that article is generated by the Manim scenes here, and
the worked Fan-Vercauteren example is a single readable NumPy file.

## Layout

```
manim/scenes/    one scene per figure, s01 to s19, plus a shared theme
manim/render_all.sh
code/fv_toy.py       the complete toy FV scheme: keygen, encrypt, decrypt, add, multiply
code/noise_plots.py  regenerates the noise-growth figures
```

## Rendering the figures

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r manim/requirements.txt
cd manim && ./render_all.sh
```

Output lands in `manim/media/`, which is gitignored. The rendered PNG, GIF and MP4
assets are served from the article itself at `https://al-am.in/blog/assets/`.

## Running the toy scheme

```bash
pip install -r code/requirements.txt
python3 code/fv_toy.py
```

The parameters in `fv_toy.py` are deliberately tiny so the numbers fit on a screen.
They are not secure and are not meant to be.
